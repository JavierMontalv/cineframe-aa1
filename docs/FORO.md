## Foro DOM y CSSOM

El DOM y el CSSOM son fundamentales para construir sitios web interactivos porque permiten al navegador representar la estructura y la presentación de una página. El DOM organiza los elementos HTML como un árbol de objetos. A través de JavaScript podemos consultar y modificar esos elementos, responder a eventos y actualizar información sin recargar toda la página. Por su parte, el CSSOM representa las reglas y declaraciones CSS que el navegador utiliza para calcular los estilos de los elementos. Ambos participan en la construcción de la representación visual del sitio, junto con las etapas de cálculo de estilos, disposición y pintura.

En CineFrame, el DOM permite actualizar el listado cuando se busca una película, mostrar los resultados de los filtros y cambiar el contador de favoritas. Las reglas CSS y las grillas de Bootstrap ajustan la presentación a móvil, tablet y escritorio. Además, el control de tamaño de lectura modifica una propiedad CSS personalizada para cambiar la presentación de las reseñas conservando el contenido.

Considero que comprender estos modelos ayuda a separar contenido, presentación y comportamiento. También permite tomar mejores decisiones de accesibilidad y rendimiento: usar HTML semántico, mantener estilos organizados y evitar modificaciones innecesarias que provoquen nuevos cálculos de disposición o pintura.

## Foro: influencia del diseño HTML y CSS en el marketing

Desde mi punto de vista, un buen diseño HTML y CSS influye directamente en la experiencia que una empresa ofrece a sus visitantes. Una estructura semántica facilita la comprensión del contenido y el uso de tecnologías de asistencia. Los estilos aportan jerarquía visual, coherencia de marca, contraste y adaptación a diferentes dispositivos.

Si una página resulta clara y cómoda desde un teléfono, el usuario puede encontrar información y completar acciones con menos dificultades. Esto puede favorecer la confianza y la conversión, aunque los resultados también dependen del contenido, la propuesta de valor y el rendimiento del sitio. En CineFrame, por ejemplo, los filtros visibles, las fichas organizadas y una navegación consistente reducen el esfuerzo necesario para elegir una película. Por eso entiendo el diseño frontend como una parte de la comunicación y del servicio al usuario, además de su función estética.

## Dos comentarios orientativos para compañeros

Estos textos son bases para adaptar después de leer las publicaciones reales. No sustituyen respuestas relacionadas con lo que cada compañero haya escrito.

### Si un compañero destaca el diseño responsive

Me parece relevante el punto que planteas sobre la adaptación a diferentes dispositivos. Añadiría que un diseño responsive también debe conservar la facilidad de navegación y la legibilidad, no solo reducir el tamaño de los elementos. ¿Qué cambios priorizarías en el menú y los formularios para mejorar la experiencia desde un teléfono?

### Si un compañero destaca la identidad visual

Tu reflexión sobre la coherencia visual se relaciona con la confianza que transmite una marca. Considero que esa coherencia debe acompañarse de buen contraste, una jerarquía clara y tiempos de carga razonables. ¿Cómo evaluarías si la elección de colores y tipografías facilita realmente la acción que la empresa espera del usuario?
